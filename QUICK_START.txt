🚀 使用流程

【步骤 1】生成问卷
cd ~/.claude/skills/skill-hads-assessment
python src/publisher.py --patient-id P001

输出：
  ✓ 问卷已生成: deployed/questionnaires/hads_P001_xxx.html
  ✓ 下一步提示

【步骤 2】发布到公网（在 AI 对话中）
用 EdgeOne MCP 发布 deployed/questionnaires/hads_P001_xxx.html

输出：
  ✓ 公网链接: https://mcp.edgeone.site/share/xxxxx?patient_id=P001

【步骤 3】患者填写
  ✓ 患者通过链接访问问卷
  ✓ 填写 14 题（5-10 分钟）
  ✓ 提交后查看结果
  ✓ 下载 JSON 文件（hads_result_P001.json）

【步骤 4】结果分析（可选）
python src/result_parser.py results/json/hads_result_P001.json

输出：
  ✓ 详细的评估报告
  ✓ 焦虑/抑郁评分
  ✓ 个性化建议

【步骤 5】整合到病情报告
cp results/json/hads_result_P001.json \
   ~/skill-report-genie/patient_data/P001/

cd ~/skill-report-genie
python process_single.py --patient-id P001

输出：
  ✓ 检测到心理评估数据 (HADS)
  ✓ 已整合到综合病情报告
