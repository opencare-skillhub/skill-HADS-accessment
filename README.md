# HADS 心理量表评估助手

## 📌 项目定位与价值

这是一个基于国际标准量表系统（HADS）构建的智能化评估工具。

**我们的观点：**
本 Skill 工具旨在通过数字化的方式，帮助**心理志愿者**、**心理医生**以及**部分患者与家属**，快速、准确地评估心理健康状态。通过将标准化的量表评估融入日常的**病情管理**和**咨询体系**，我们能够实现情绪风险的早期筛查、动态追踪与及时干预，为患者提供更有温度的数字医疗支持。

## 🚀 核心功能

1.  **标准化评估**：基于 HADS（医院焦虑抑郁量表）标准，提供焦虑（HADS-A）与抑郁（HADS-D）双维度测评。
2.  **交互式问卷**：生成高品质、治愈系 UI 的在线问卷，支持多端访问。
3.  **智能自动计分**：实时计算得分并根据临床标准提供风险等级判别。
4.  **结构化数据产出**：输出标准 JSON 格式结果，无缝对接综合病情管理系统。
5.  **反思自优化**：内置日志分析与自优化机制，持续提升评估的语义精度与流程稳定性。

## 👥 适用人群

*   **心理志愿者**：在社区或机构调研中快速开展心理健康普查。
*   **心理医生**：作为临床咨询的辅助工具，获取客观的量化数据。
*   **患者及家属**：进行居家自我监测，及时掌握情绪波动，主动寻求专业支持。

## 🛠️ 环境准备

为了确保 Skill 的正常运行与自动化编排，请在开始前完成以下准备工作：

1.  **路径规范**：请将本项目文件夹放置或链接至以下标准路径：
    `~/.claude/skills/skill-hads-assessment`
2.  **依赖安装**：在项目根目录下执行以下命令安装必要的 Python 依赖包：
    ```bash
    pip install -r requirements.txt
    ```
3.  **环境校验**：确保您的 Python 环境版本 >= 3.8，并已配置好基础的 MCP 运行环境。
